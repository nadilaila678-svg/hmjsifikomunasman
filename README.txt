WEBSITE HMJSI FIKOM UNASMAN
==========================

ISI FOLDER
- index.html       : Beranda
- profil.html      : Profil, visi, misi, dan tabel struktur pengurus
- kegiatan.html    : Program, agenda, dokumentasi, dan video
- kontak.html      : Informasi kontak dan formulir aspirasi
- images/          : Tempat menyimpan logo dan foto kegiatan
- media/           : Tempat menyimpan video dokumentasi

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder, lalu pilih folder website-hmjsi-fikom-unasman.
4. Salin logo organisasi ke folder images dan beri nama: logo-hmjsi.png
5. (Opsional) Tambahkan foto kegiatan:
   - images/kegiatan-1.jpg
   - images/kegiatan-2.jpg
6. (Opsional) Tambahkan video dokumentasi:
   - media/profil-kegiatan.mp4
7. Buka index.html di browser (klik kanan > Open with Live Server jika ekstensi tersedia).
8. Uji semua menu navigasi dan formulir.

CATATAN PENTING
- Website dibuat dengan HTML5 murni. Tidak ada CSS atau JavaScript.
- Data sejarah, visi, misi, nama pengurus, periode, agenda, email, dan media sosial
  belum diberikan. Ganti teks petunjuk/contoh dengan data resmi HMJSI.
- Tabel kepengurusan adalah contoh format, bukan data pengurus sebenarnya.
- Formulir masih berupa contoh antarmuka. Data belum tersimpan atau terkirim karena
  website statis belum memiliki backend atau layanan formulir.
- Pada halaman kegiatan, gambar dan video harus ditambahkan sendiri agar tampil.
- Letakkan logo asli yang dimiliki pada images/logo-hmjsi.png.
